# touchgrass

For the terminaly online people to touch grass...

## Install

```bash
npm install -g go-touch-grass
```

## Usage

```bash
# Run a random grass-touching animation
touchgrass

# Run a breathing meditation
touchgrass breathe
```

## What happens

You'll get one of three animations:

- **Your Local Park**
- **Swiss Alps**
- **Japanese Garden** 


## Run without installing

```bash
npx go-touch-grass
```
